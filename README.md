## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/MAVIVO1/RealHailePortfolio-s.git
   ```
2. Go to the source folder
   ```bash
   cd RealHailePortfolio-s/hailemariam-portfolio/portfolio_src
   ```
3. Open `index.html` in your browser.

   If the project uses Node.js, run this instead:
   ```bash
   npm install
   npm start
   ```
